# Explore in HarmonyOS

**Open source sample apps, how-to projects and libraries for HarmonyOS wearable development.**

Every project is a standalone repository you can clone, open in DevEco Studio and run.

**[Browse all projects](https://github.com/Explore-In-HMOS/hmos-index)** &nbsp;·&nbsp; **[Getting started](https://github.com/Explore-In-HMOS/hmos-index/blob/main/docs/GETTING_STARTED.md)** &nbsp;·&nbsp; **[Troubleshooting](https://github.com/Explore-In-HMOS/hmos-index/blob/main/docs/TROUBLESHOOTING.md)**

### What you will find here

| | Platform | Language |
|---|---|---|
| ⌚ **Sample applications**: complete apps such as fitness trackers, games, health and productivity tools | Smart Wearable | ArkTS |
| 🛠️ **How-to projects**: one focused topic each, from sensors, maps and notifications to security and UI components | Smart Wearable | ArkTS |
| ⌚ **Sportwatch apps and how-tos**: repositories whose name starts with `sportwatch-` | Lite Wearable | JavaScript |
| 📦 **Libraries**: reusable ArkTS components | Smart Wearable | ArkTS |
| 📱 **Companion and cross-platform apps**: phone-side apps that talk to the watch | Android, iOS, cross-platform | Kotlin, Swift, Flutter, React Native |

The full, categorized list of 550+ projects lives in **[hmos-index](https://github.com/Explore-In-HMOS/hmos-index)**.
